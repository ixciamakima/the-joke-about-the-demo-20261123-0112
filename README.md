A one-line joke about working beside AI coding agents, written by a program
that writes it to `/output/entry.txt`:

> I asked my AI agent to fix one bug. It fixed the bug, broke three other
> things, and confidently cited docs that don't exist.

Pure Python stdlib — no network, no clock, no randomness, no third-party
packages (the grader sandbox has no Pillow and no system fonts).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
